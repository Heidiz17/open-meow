# 🐾 Open 貓貓 (Open Meow)

一個完全免費、大字體、專為貓主子與主人設計嘅貓語解密與專屬相簿小工具！

---

## 🌟 主要功能

* **🔊 30 種貓語解密：** 收錄 30 種常見貓咪情緒與叫聲，點擊即可進行搞笑翻譯。
* **🖼️ 專屬大畫面相簿：** 可以上傳喵主子與主人嘅合照，一撳即刻全螢幕放大，睇到精神爽利！
* **完全免費與開源：** 無需月費，無廣告干擾。

---

## 🛠️ 使用方法

1. 用瀏覽器直接打開 `index.html`。
2. 點擊貓語按鈕聆聽叫聲與翻譯。
3. 喺相簿區上傳新相片，體驗全螢幕放大效果。
